Concepto crítico

Transacciones

Cualquier cambio al modelo debe ir dentro de un Transaction.
Sin transacción → excepción inmediata.
Esto te da undo automático en Revit y permite agrupar varios cambios en una sola operación. 
using (Transaction tx = new Transaction(doc, "Crear muro"))
{
    tx.Start();

    // modificar el modelo aquí
    Wall.Create(doc, curve, levelId, false);

    tx.Commit();
}

La misma clase, dos lenguajes

HelloRevit en C# vs VB.NET

C# · recomendado
[Transaction(TransactionMode.ReadOnly)]
public class Command : IExternalCommand
{
    public Result Execute(
        ExternalCommandData data,
        ref string message,
        ElementSet elements)
    {
        TaskDialog.Show("Hola", "Revit");
        return Result.Succeeded;
    }
}
VB.NET · más verboso
<Transaction(TransactionMode.ReadOnly)>
Public Class Command
    Implements IExternalCommand

    Public Function Execute(
        data As ExternalCommandData,
        ByRef message As String,
        elements As ElementSet) _
        As Result Implements _
        IExternalCommand.Execute

        TaskDialog.Show("Hola", "Revit")
        Return Result.Succeeded
    End Function
End Class

6.3 · Paso 10 · Pega este código

Command.cs

using Autodesk.Revit.Attributes;
using Autodesk.Revit.DB;
using Autodesk.Revit.UI;

namespace HolaRevit
{
    [Transaction(TransactionMode.ReadOnly)]
    [Regeneration(RegenerationOption.Manual)]
    public class Command : IExternalCommand
    {
        public Result Execute(
            ExternalCommandData commandData,
            ref string message,
            ElementSet elements)
        {
            UIApplication uiApp = commandData.Application;
            Document doc = uiApp.ActiveUIDocument.Document;

            string nombreProyecto = doc.ProjectInformation.Name;
            string archivo = string.IsNullOrEmpty(doc.PathName)
                ? "(sin guardar)"
                : doc.PathName;
            int totalElementos = new FilteredElementCollector(doc)
                .WhereElementIsNotElementType()
                .GetElementCount();

            TaskDialog dlg = new TaskDialog("¡Hola Revit!")
            {
                MainInstruction = $"¡Hola, {nombreProyecto}!",
                MainContent =
                    $"Archivo: {archivo}\n" +
                    $"Versión Revit: {uiApp.Application.VersionNumber}\n" +
                    $"Build: {uiApp.Application.VersionBuild}\n" +
                    $"Total de elementos en el modelo: {totalElementos}",
                CommonButtons = TaskDialogCommonButtons.Ok
            };
            dlg.Show();

            return Result.Succeeded;
        }
    }
}

¿Qué hace cada parte?

Lectura del código

[Transaction(TransactionMode.ReadOnly)]Solo lee el modelo, no lo modifica.
IExternalCommandContrato obligatorio para ser un comando.
commandData.ApplicationPuerta de entrada a TODA la API.
FilteredElementCollectorLa herramienta más usada de la API. Filtra elementos del modelo.
TaskDialogDiálogo nativo de Revit. No uses MessageBox de WinForms.

public class App : IExternalApplication
{
    public Result OnStartup(UIControlledApplication app)
    {
        string tab = "Arkadis";
        app.CreateRibbonTab(tab);
        RibbonPanel panel = app.CreateRibbonPanel(tab, "Hola");

        var btn = new PushButtonData(
            "btnHola", "Hola\nRevit",
            Assembly.GetExecutingAssembly().Location,
            "HolaRevit.Command");

        panel.AddItem(btn);
        return Result.Succeeded;
    }

    public Result OnShutdown(UIControlledApplication app)
        => Result.Succeeded;
}
